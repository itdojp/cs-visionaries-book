# 序章：スマホの中に眠る天才たちの遺産

## あなたの一日は、多くの先駆者が作った技術で始まる

### 朝7時、アラームが鳴る瞬間

朝7時。スマートフォンのアラームが鳴り響く。この単純な音の背後には、驚くべき技術の歴史が隠されている。

音がデジタル信号として処理され、スピーカーから再生される—この仕組みを可能にしたのは、1940年代にコンピュータの基礎を築いた人々だった。**グレース・ホッパー**が機械語をより人間に近い言葉に変換する技術を開発していなければ、あなたのアラームアプリは存在しなかっただろう。

アラームの音源ファイルは、デジタル信号処理の魔法によって圧縮されている。0と1の二進数で音を表現する—この発想は、**アラン・チューリング**が「計算可能性」について考察した結果生まれたものだ。

### タッチスクリーンに触れるとき

アラームを止めようと、あなたは画面に指を滑らせる。この瞬間、画面は微弱な電気信号の変化を検知し、タッチ位置を特定する。

タッチスクリーン技術の背景には、人間とコンピュータの対話方法を根本から変えた革命がある。**スティーブ・ジョブズ**と**スティーブ・ウォズニアック**が1970年代に始めた「コンピュータを誰もが使えるものにする」という挑戦。彼らがマウスとグラフィカルユーザーインターフェース（GUI）を普及させていなければ、今のような直感的な操作は不可能だった。

画面に表示されるアイコンやボタン—これらはすべて、**エイダ・ラブレス**が1843年に想像した「機械が記号を扱える」という概念の実現だ。彼女は数値だけでなく、音楽や言葉さえも機械で処理できると予言していた。

### メッセージアプリを開く

メッセージアプリのアイコンをタップすると、瞬時に友人からのメッセージが表示される。この裏では、世界中のサーバーとあなたのスマートフォンが、複雑なネットワークでつながっている。

インターネットの基盤となるパケット通信—データを小さな塊に分割して送信し、目的地で再構成する技術。この基盤の上に、**ティム・バーナーズ＝リー**はWorld Wide Webを築き、情報共有の方法を根本から変えた。インターネットとWebの違いを意識すると、後の検索・クラウド・AI への流れも追いやすくなる。

メッセージが暗号化されて送信されることをご存知だろうか。この暗号技術の基礎は、第二次世界大戦中にナチスの暗号「エニグマ」を解読した**アラン・チューリング**の功績に遡る。現代の暗号技術は、彼の計算理論なしには成立しなかった。

### 検索窓に文字を入力する

何か調べたいことがあり、検索アプリを開く。文字を入力し始めると、予測変換が働き、関連する検索候補が表示される。

この魔法のような機能の背後には、**ラリー・ペイジ**と**セルゲイ・ブリン**が開発したPageRankアルゴリズムがある。彼らは「Web全体を整理する」という壮大な夢を抱き、情報の重要度を数学的に評価する方法を編み出した。

検索結果が瞬時に表示される—この高速処理を可能にしているのは、**ジェフ・ベゾス**が普及させたクラウドコンピューティングだ。世界中のデータセンターが協調して動作し、あなたの検索要求に応える。

### 写真を撮ってSNSに投稿

朝の風景を撮影し、SNSに投稿する。カメラが自動的にピントを合わせ、色を調整し、美しい写真に仕上げる。

この小さなカメラセンサーとプロセッサーは、**嶋正利**が共同開発し、Intelが「first general-purpose microprocessor」と位置づけるIntel 4004の子孫だ。1971年に誕生したこの小さなチップが、今では何十億個ものトランジスタを搭載し、瞬時に画像処理を行っている。

写真をSNSに投稿すると、世界中の友人に共有される。この「つながり」の価値を見出し、プラットフォーム化したのが**マーク・ザッカーバーグ**だ。彼は大学の寮室から始めたプロジェクトで、人類の交流方法を永遠に変えてしまった。

## 本書の読み方と登場人物・テーマ

ここまで見てきたように、あなたが日常的に使っているテクノロジーは、過去200年間にわたる先駆者たちの挑戦と革新の積み重ねだ。本書では、人物章とテーマ章を行き来しながら、デジタル革命の成り立ちを多面的に追っていく。

注記: 正式な章立て・読み順・取り上げる人物/テーマの一覧は、トップページの目次と「取り上げる人物・テーマ」を正とします。序章は、本書全体へ入る前に「何が今のスマートフォンやクラウド、AI を支えているのか」を掴むための導入です。

### 序章で押さえたい読みどころ

- **計算理論から製品までが一本の流れでつながること**: アラーム、検索、SNS、クラウド、AI が別々の発明ではなく、積み重なった選択の結果であると掴む
- **人物だけでなくテーマ章も読む理由**: Web、検索、SNS、クラウド、現代AIのようなテーマ章を挟むことで、個人の功績が社会実装へ接続される過程を追いやすくする
- **AI を読む入口**: 現行公開版では第10章が AI の主導入であり、深層学習の技術史や関連文献は付録Cと関連人物章を併用して補う
- **読書会や研修での使い方**: 序章は議論の導入に使い、正式な読み順や補助資料への戻り先はトップページ・付録A〜Dで確認する

### 本書の特徴

本書は単なる技術史や伝記ではない。以下の視点を重視している。

- **現代との接続** - 各章で、その人物の功績が現在のテクノロジーにどう生きているかを解説する
- **人間ドラマ** - 成功だけでなく、失敗、苦悩、人間関係も描写する
- **ビジネスへの示唆** - 各章末に、現代のビジネスパーソンが学べる教訓を提示する
- **ビジュアル重視** - 図解、写真、インフォグラフィックを多用し、理解を助ける

### 読者へのメッセージ

テクノロジーは決して無機質なものではない。それは人間の創造性、情熱、そして夢の結晶だ。本書を通じて、あなたには以下のことを感じていただければ幸いだ：

1. **技術への親近感** - 難しそうな技術も、人間のストーリーを通じて理解できる
2. **革新への勇気** - 偉大な発明も、最初は一人の「もしも」から始まった
3. **未来への希望** - 過去の革新者たちが夢見た未来に、私たちは生きている

さあ、デジタル革命の舞台裏への旅を始めよう。最初の主人公は、200年前のロンドンに生きた一人の貴婦人—エイダ・ラブレスだ。

### 序章で登場した主な人物とキーワード

- エイダ・ラブレス：世界初のプログラマーとされる貴婦人。解析機関と Note G、機械による創造性の可能性。
- アラン・チューリング：計算理論と暗号解読の先駆者。チューリングマシンと計算可能性、現代暗号の基盤。
- グレース・ホッパー：コンパイラの発明と高水準言語の普及。人間に近い言葉で機械を操作するという発想。
- 嶋正利：Busicom側技術者としてIntel 4004を共同開発。高橋秀俊：ETLのtransistor計算機研究を率いた先駆者。異なる技術系列から「コンピュータの小型化」を読む。
- スティーブ・ジョブズ&スティーブ・ウォズニアック：パーソナルコンピュータと GUI の普及。誰もがコンピュータを使える世界を目指した起点。
- ティム・バーナーズ＝リー：World Wide Web の発明。ハイパーリンクと URL による情報の解放。
- ラリー・ペイジ＆セルゲイ・ブリン：PageRank に代表される検索アルゴリズム。世界の情報を整理するという構想。
- マーク・ザッカーバーグ：SNS プラットフォームを通じた「つながり」の可視化とビジネス化。
- ジェフ・ベゾス：EC とクラウドコンピューティングの拡大。長期思考とプラットフォーム戦略。

これらの人物やキーワードの詳細は、以降の各章で改めて丁寧に取り上げていきます。序章では「スマートフォンの一日の裏側に、どのような歴史が隠れているか」をざっくりと掴む程度でも構いません。
