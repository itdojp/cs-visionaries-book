# Legacy asset snapshot

この `cs-visionaries-book/` 配下は、過去の生成物や実験用資産の残骸です。現行の編集先や reader-facing な正本ではありません。

- 現行の公開確認基準: `docs/` と GitHub Pages
- 現行の編集起点: `src/`
- CSS / JS の修正先: `templates/styles/`・`templates/js/`（必要に応じて `assets/`。`docs/assets/` は `npm run build` 時に再生成される生成物です）

この配下の `docs/assets/*` はビルド生成物かつ legacy / non-canonical として扱い、現行の差分判断には使わないでください。
